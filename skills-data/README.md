# Skills Data

This folder contains raw skill data, metadata, and scraped content from various sources.

## Structure

- `anthropic/` - Skills from Anthropic's public GitHub repository
- `raw/` - Raw scraped data and JSON files
- `processed/` - Cleaned and structured skill data ready for evaluation

## Data Sources

- Primary: https://github.com/anthropics/skills
- Future: SkillsMP, community-contributed skills

## Notes

- Keep raw data separate from processed data
- Use consistent naming: `skill-name.json` or `skill-name.md`
- Include metadata: source, date collected, version
