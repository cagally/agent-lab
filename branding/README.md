# Branding

This folder contains brand guidelines, visual assets, messaging frameworks, and brand identity materials.

## Contents

**Guidelines:** Brand voice, tone, visual identity  
**Assets:** Logos, color palettes, typography, imagery  
**Messaging:** Value propositions, taglines, positioning  

## Brand Direction

The brand should feel authoritative yet accessible, positioning the platform as the definitive hub for agent skills. The visual and verbal identity must appeal to both technical and non-technical users while emphasizing simplicity, clarity, and trust.
