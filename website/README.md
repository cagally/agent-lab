# Website

This folder contains all website-related assets, code, designs, and deployment configurations.

## Tech Stack

**Frontend:** Lovable (or similar rapid development platform)  
**Backend/Database:** Supabase (if needed for dynamic data)  
**Deployment:** Fast, simple hosting solution  

## MVP Features

The MVP focuses on speed and core functionality. The website provides a clean discovery interface with Airbnb-style skill cards, search and filtering capabilities, detailed skill pages with scorecards and ratings, and a non-technical interface that anyone can understand.

## Design Principles

Keep it simple and clean. Optimize for speed to market. Make it immediately useful with our initial 20-50 skills. Ensure the design is scalable for future features.
