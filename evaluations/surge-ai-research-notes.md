# Surge AI Research Notes

**Date:** Dec 25, 2025  
**Purpose:** Understand Surge AI's evaluation methodology to inform our skill evaluation framework

---

## Key Findings

### Surge AI's Core Methodology

**What They Do:**
- Provide high-quality human feedback for training and evaluating LLMs
- Focus on RLHF (Reinforcement Learning from Human Feedback)
- Partner with frontier labs like Anthropic, OpenAI

**Their Differentiators:**

1. **Proprietary Quality Control Technology**
   - Advanced human/AI algorithms
   - Built by scientists and researchers
   - Designed to catch low-quality data that sets work back by years

2. **Domain Expert Labelers**
   - 200,000+ experts globally
   - Mathematicians, physicists, computer scientists, poets, philosophers
   - Professionals: lawyers, doctors, VCs, CEOs, consultants, professors
   - 80+ countries, 500+ languages, 30,000+ skills

3. **Rapid Experimentation Interface**
   - APIs for integration
   - Quick job launch without months of guideline writing
   - Iterate fast

4. **Red Teaming Tools**
   - Adversarial testing to find flaws, biases, vulnerabilities
   - Uncover holes in safety defenses

5. **Deep RLHF Expertise**
   - Proven methods from hundreds of internal experiments
   - No constant recalibration needed

## What We Can Learn

### For Our Skills Evaluation Platform:

**Parallel to Surge AI's Approach:**

| Surge AI (LLM Evaluation) | Our Platform (Skills Evaluation) |
|---------------------------|----------------------------------|
| Human experts label LLM outputs | We test skills with real prompts |
| Quality control algorithms | Automated + manual testing rubrics |
| Domain experts (lawyers, doctors) | Domain-specific skill testing |
| Red teaming for safety | Failure mode discovery |
| Rapid experimentation | Fast eval cycles, quick iteration |
| RLHF expertise | Skills evaluation expertise |

**Key Insight:** Surge AI's value isn't just "testing" - it's:
1. **Systematic rubrics** for evaluation
2. **Quality control** that catches subtle issues
3. **Expert-level evaluation** (not just crowdsourced)
4. **Adversarial testing** to find edge cases
5. **Proven methodology** that clients trust

## Key Takeaways

1. **Quality > Speed** - Surge AI's value is in catching issues others miss
2. **Systematic Rubrics** - Not ad-hoc testing, but repeatable frameworks
3. **Expert Evaluation** - Domain knowledge matters
4. **Adversarial Testing** - Actively try to break things
5. **Proven Methodology** - Build trust through consistent results

**Our Moat:** Be the "Surge AI of Skills" - the trusted evaluation platform that skill creators and users rely on for quality assurance.
