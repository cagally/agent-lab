# Evaluations

This folder contains the evaluation framework, test results, scorecards, and quality ratings for agent skills.

## Contents

**Framework:** Core evaluation methodology and criteria  
**Results:** Individual skill evaluation results and scorecards  
**Reports:** Aggregate analysis and insights across skills  

## Evaluation Approach

The evaluation framework assesses skills across multiple dimensions to provide actionable insights for users. Results are stored as structured data that feeds directly into the website's skill cards and comparison tools.
